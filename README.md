# FinoraUI

FinoraUI is a custom user interface plugin for Jellyfin. It aims to provide an enhanced, modern, and seamless experience for browsing and watching your media.

## Features
- Custom styling for the Jellyfin web interface.
- Enhanced video player interface.
- Easy to install via Jellyfin's plugin system.
