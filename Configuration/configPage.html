FinoraUI

Restyles Jellyfin Web with a dark, cinematic look. The color/layout changes are applied through the server's built-in Branding > Custom CSS setting.

Writes the skin's stylesheet into Branding > Custom CSS.
Used for focus rings, the active nav pill, and progress bars. Example: #ffffff
Adds the FinoraUI home hero/rail behaviour to Jellyfin Web.

Ratings (MDBList)

Optional. Adds rating badges to the meta info row on the home hero and detail screen, looked up through MDBList's API, which aggregates IMDb, TMDB, Rotten Tomatoes, Metacritic, Trakt, Letterboxd and Roger Ebert in one lookup.

Your personal MDBList API key. Stored in this plugin's configuration.

Choose which rating sources are shown, and drag to reorder them. Only checked sources appear, in the order listed.

Age rating

Optional. Jellyfin's own age-rating field only ever stores ONE certification - whichever country your server's metadata settings are configured for. Adding a TMDB API key lets the meta info row's age badge prefer the default country's certification instead, falling back to the fallback country only when a title has no certification for the default country. Left empty, the badge keeps using Jellyfin's own OfficialRating value, same as always.

Your personal TMDB (v3) API key. Stored in this plugin's configuration.
Preferred certification country - used as-is, with no country prefix.
Used only when a title has no certification for the default country above - shown prefixed with its country code.

Video player buttons

Choose which buttons appear in the video player controls.

Restart required: restart the Jellyfin server after saving for these changes to take effect.
