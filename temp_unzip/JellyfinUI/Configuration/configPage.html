IMDb ratings

Optional. Adds an IMDb rating badge to the meta info row, looked up through OMDb's free API.

Your personal OMDb API key. Stored in this plugin's configuration.

Age rating

Optional. Jellyfin's own age-rating field only ever stores ONE certification - whichever country your server's metadata settings are configured for. Adding a TMDB API key lets the meta info row's age badge prefer the US certification instead, falling back to India (IN) only when a title has no US certification. Left empty, the badge keeps using Jellyfin's own OfficialRating value, same as always.

Your personal TMDB (v3) API key. Stored in this plugin's configuration.
